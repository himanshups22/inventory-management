System Architecture

Data Flow (Filter Example)

1

User Selects Filter

FilterBar.vue updates reactive refs in the global useFilters() composable (singleton pattern). Supports 4 filters: Time Period, Warehouse, Category, Order Status.

2

Watch Triggers Reload

Each view component uses watch() on filter refs. When a filter changes, the view calls its load function (e.g., loadOrders()).

3

API Request via Axios

api.js sends an HTTP GET with filter values as query parameters: /api/orders?warehouse=Tokyo&month=2025-03

4

FastAPI Filters In-Memory Data

main.py receives the request, applies apply_filters() and filter_by_month() sequentially on the in-memory dataset loaded from JSON files.

5

Pydantic Validates Response

Filtered results are validated against Pydantic models (InventoryItem, Order, etc.) and serialized as JSON.

6

Vue Renders Updated Data

The view stores the response in a ref(). Computed properties derive display values. The template re-renders via Vue's reactivity system.
